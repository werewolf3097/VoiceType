# VoiceType (macOS MVP)

Голосовой ввод в строке меню: зажал клавишу — говоришь — отпустил — текст расшифрован (gapi)
и, если задан ключ Claude, дополнительно очищен от слов-паразитов/оформлен (Anthropic API) —
результат в буфере обмена и, по желанию, вставлен в активное поле.

## Запуск

```bash
cd VoiceType
xcodegen generate   # если меняли project.yml или добавляли файлы
open VoiceType.xcodeproj
```

В Xcode: выбрать схему **VoiceType** → Run (⌘R). Значок появится в строке меню (значок микрофона),
иконки в Dock не будет — это утилита только для меню-бара.

Пересобрать из терминала можно так же, без Xcode:

```bash
xcodebuild -project VoiceType.xcodeproj -scheme VoiceType -configuration Debug build \
  CODE_SIGN_IDENTITY="-" CODE_SIGNING_REQUIRED=NO
```

## Собрать отдельный .app

```bash
./build-app.sh
```

Соберёт Release-версию и положит `VoiceType.app` рядом с папкой проекта — можно запускать
двойным кликом или перетащить в `/Applications`. Подпись ad-hoc («Sign to Run Locally») — этого
достаточно для запуска на этом же Маке; при первом запуске система может один раз попросить
подтвердить открытие через правый клик → «Открыть» (файл не нотаризован).

Если проект лежит в папке, синхронизируемой iCloud (например, на рабочем столе с включённым
«Рабочий стол и Документы»), сама сборка всё равно идёт через стандартный DerivedData —
так codesign не спотыкается о служебные атрибуты, которые iCloud добавляет на лету.

Чтобы раздать сборку другим людям (не только на этой машине), нужны Apple Developer ID и
нотаризация — без этого Gatekeeper на чужих Mac будет блокировать запуск.

## Настройка при первом запуске

1. Открыть **Настройки…** из меню приложения.
2. Вставить **токен gapi** (создаётся в кабинете [console.gapi.uz](https://console.gapi.uz) →
   вкладка «API-токены»).
3. Опционально вставить **Anthropic API key** ([console.anthropic.com](https://console.anthropic.com)) —
   нужен только для пункта «Обработка текста» (грамматика / заметка / сообщение). Без ключа
   текст просто вставляется как есть после распознавания.
4. Выбрать клавишу push-to-talk (по умолчанию — правый Option).
5. Разрешить два системных доступа (macOS спросит сама при первом использовании, либо открыть
   вручную кнопками в настройках приложения):
   - **Системные настройки → Конфиденциальность и безопасность → Мониторинг ввода** — без этого
     приложение не увидит нажатие хоткея нигде, кроме себя самого.
   - **Микрофон** — для самой записи.
   - Если включена **автовставка** — может понадобиться **Accessibility**, чтобы симуляция
     ⌘V сработала в других приложениях.

После выдачи разрешения «Мониторинг ввода» может понадобиться перезапустить приложение
(Выйти → снова Run/открыть .app).

## Как это работает

- `AudioRecorder` — запись в WAV 16kHz/mono через `AVAudioRecorder`.
- `HotkeyManager` — глобальный `CGEventTap` на `.flagsChanged`, ловит зажатие/отпускание
  выбранной клавиши-модификатора (push-to-talk), без блокировки события для других приложений.
- `GapiClient` — `POST /v1/transcribe` (синхронный режим, записи до 5 минут); при долгой обработке
  API отвечает 202 и клиент переходит на опрос `GET /v1/jobs/{id}` → `/result`.
- `ClaudeClient` — `POST /v1/messages` (модель `claude-sonnet-5`), используется только если задан
  ключ и выбран стиль обработки, отличный от «Без обработки».
- `TextInjector` — копия в `NSPasteboard` + опциональная симуляция ⌘V через `CGEvent`.
- Ключи хранятся в Keychain (`KeychainStore`), не в `UserDefaults` и не в коде.

**Важно про gapi:** сервис распознаёт только узбекскую речь (результат — латиницей). Для
русского/английского ввода понадобится другой STT-движок — если такое нужно, это отдельная задача.

## Другие платформы

Фокус сейчас — только desktop:

- [voicetype-windows](https://github.com/werewolf3097/voicetype-windows) — WinUI 3, глобальный
  хоткей через low-level keyboard hook, вставка через `SendInput`.

iOS и Android сознательно отложены до проверки продукта на desktop — вернёмся к ним, если
продукт получится хорошим. Прежние scaffolding-репозитории удалены; архитектурные решения
сохранены в

Общий поток данных и контракты внешних API — в
